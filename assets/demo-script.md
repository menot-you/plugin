# nSOUL demo — the spoken walkthrough

One uninterrupted terminal session, real repository gates, brand theme. Three acts.

## Opener

nSOUL is the operating core of NOTT, packaged as a plugin. This is what it ships and
the one rule it enforces — shown against the repository's own gates, not a mockup.

## Act 1 — the surface

`nsoul skills` lists the 11 engineering skills; `nsoul agents` lists the 6 bounded
agents. Each skill owns a method end to end; each agent carries a narrow charter. Plus
4 registered hooks that run on every turn. That is the whole operating surface.

## Act 2 — the one rule

`nsoul rule` states what the hooks enforce: claim only what you can prove, and close
every turn with one next action — a proven result or the exact gap. Never confident
hand-waving.

## Act 3 — watch it refuse

`nsoul refuse` plants a document whose normative clause both commands and hedges in
the same breath — the exact anti-pattern the gate forbids — and runs the repository's
`doc-lint`. The gate rejects it: *hedge in normative paragraph*. The rule is machinery, not manners — a
violation does not merge.

## Close

The discipline is not a promise in a prompt an attacker can talk around. It is skills,
bounded agents, and hooks, with each rule's red test proving the gate rejects a real
violation. Clone-and-own on Claude Code or Codex.
