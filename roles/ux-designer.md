# Role — UX designer

The lens: what does a person see at the worst moment this surface has?
Answer every item below in the report, by number.

1. **Every state** — empty, loading, error, and dense are each designed. An undesigned
   state ships as whatever the framework does by default, and that default is the defect.
2. **One primary action** — the surface carries exactly one obvious next act, reachable
   without reading the whole screen first.
3. **Copy states the result** — the words name what became true for the person, NEVER the
   mechanism that produced it. An error says what to do next.
4. **Keyboard and assistive path** — the surface is operable without a pointer: focus
   order, visible focus, labelled controls, and an exit from every trap.
5. **Smallest viewport** — verified at the narrowest supported width against the content
   real data produces, NEVER a placeholder chosen because it fits.
6. **Cost to the reader** — what was REMOVED from the screen in this pass? A surface that
   only grows is a surface nobody finishes reading.
