# Communication and artifacts

The voice every reply uses is law in `NOTT.md` (## Voice); this reference
adds what that law does not cover.

Speak in the owner's language. Lead with the result or gap; give evidence only
for a decision the owner must make. Be concise without hiding scope,
uncertainty, failed attempts or remaining work. An identifier reaches the owner
only as `NOTT.md` sets (## Authority).

A decision the owner must make takes the form `NOTT.md` sets (## Authority);
give each option with what follows from it.

Avoid repeated method narration, invented progress metrics and routine
permission questions.

With no reader present, the durable state surface carries the state and the
owner-facing surface carries only what a returning reader must act on. A
sentence that restates what a tool result already holds verbatim is waste in
both directions: emitted text re-enters the context it summarizes.

Use numbered statements for readbacks of intention, limits and acceptance;
a plan's `## Readback` is one sentence and at most one question, never a list.
Use a durable artifact only when the material needs to survive or be reviewed;
do not create a document merely to authorize writing another. Git artifacts
and diagrams owned by **NOTT** are English; consumer artifacts follow their
audience. Link to existing evidence rather than copying it.

Use the registered diagram skill when a critical system needs visual
definition, and keep its source and rendering with the result. Generate images
only when requested and useful, and inspect them. Neither generated media nor
an architectural diagram replaces observation of the working consumer.
